# Halloween The Game Session Toolkit — feature reference

A task-oriented Halloween The Game session toolkit workspace: session profiles first, equipment notes next, and control reference as the final reference area.

| Section | Description |
|---|---|
| Session profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Control reference | A dedicated section for control reference and the configuration details associated with that area. |

The project page follows the same section structure.
